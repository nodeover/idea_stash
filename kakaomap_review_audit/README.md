# 카카오맵 리뷰 주작 감별기

카카오맵 장소 페이지가 실제로 호출하는 내부 API(`place-api.map.kakao.com`)에서
리뷰 **전량과 작성자 프로필**을 수집해, 별점이 인위적으로 부풀려졌는지 판별한다.

```bash
python3 audit.py "https://kko.to/F9Yq34Y0su" -c 604720323 106205003 715721034
python3 audit.py 1563450232 -o result.json
```

단축 URL, 장소 URL, 숫자 ID 모두 입력으로 받는다. `-c`로 같은 동네 동종 업장을
대조군으로 넣으면 상대 비교표가 함께 출력된다.

## 왜 대조군이 필요한가

"평점 4.9면 조작"은 틀린 추론이다. 진짜로 좋은 집도 4.9가 나온다.
조작은 **점수의 높이**가 아니라 **점수를 만든 사람들의 구성**에서 드러난다.
그래서 이 도구는 절대 임계값 대신 같은 상권 동종 업장의 분포와 비교한다.

## 감별 신호

| 신호 | 정상 범위 | 조작 시 | 원리 |
|---|---|---|---|
| 리뷰 1개뿐인 계정 비중 | 0~15% | 60%+ | 매장에서 그 자리에서 계정을 만들어 쓰고 버린다 |
| 사진 첨부 비율 | 30~55% | 95%+ | 대부분의 리뷰 이벤트가 사진을 조건으로 건다 |
| 5점 비율 | 35~65% | 90%+ | 보상 조건이 만점이라 중간 점수가 사라진다 |
| 작성자 평생 평점 = 5.00 | ~35% | 80%+ | 5점 한 번 주고 끝난 계정이라는 뜻 |
| 표시 평점 − 헤비유저 평점 | ~0 | 0.4점+ | 일반 이용자 집단만 남기면 진짜 점수가 보인다 |
| 식사시간대 집중도 | 분산 | 95%+ | 집에서 회상하며 쓰지 않고 테이블에서 즉석 작성한다 |

가장 결정적인 지표는 마지막 두 개다. **작성자 리뷰 수 구간별로 별점을 쪼개면**
1회성 계정과 헤비유저 사이에 낙차가 생기는데, 이 낙차가 곧 조작량이다.
헤비유저(리뷰 10개 이상)는 이벤트 참여 동기가 약하고 비교 기준이 있어서
보정 추정 평점의 기준선이 된다.

이 도구는 리뷰 본문에서 다른 손님의 "리뷰 이벤트 있는 집이니 걸러 보세요" 같은
**자백 리뷰**도 자동으로 찾아낸다. 통계보다 이쪽이 증거로서 더 강하다.

## 사례 연구: 이태리국시 한남 (place id 1563450232)

2026-09-19 기준 리뷰 2,229건 전량 + 한남동 동종 업장 5곳 대조군.
표시 평점 **4.9 / 2,229건**, 산출된 **주작 지수 89 / 100**.

```
업장                     표본    평균    5점%    사진%   1회성계정%
▶ 이태리국시 한남        2229   4.90    92.9     98.5        70.3
  오스테리아 오르조 한남   300   4.28    57.0     44.0         0.3
  쎄오                     65   4.38    63.1     53.8         1.5
  부첼리하우스             88   4.18    46.6     43.2         2.3
  테이블포포               58   3.72    44.8     36.2         0.0
  월간식당                 54   3.72    35.2     38.9         3.7
```

1회성 계정 비중이 대조군 **0~4%** 대 **70.3%**. 같은 상권 같은 업종에서
이 정도 차이는 자연 발생하지 않는다. 사진 첨부율도 대조군 36~54% 대 98.5%다.

작성자 리뷰 수 구간별로 쪼개면 낙차가 그대로 보인다.

```
  1개(1회성)   n=1567  평균 4.93  5점 94.1%  3점이하  0.8%
  2개          n= 344  평균 4.91  5점 93.6%  3점이하  1.5%
  3-5개        n= 188  평균 4.81  5점 89.4%  3점이하  4.3%
  6-9개        n=  45  평균 4.84  5점 91.1%  3점이하  2.2%
  10-29개      n=  53  평균 4.66  5점 84.9%  3점이하  9.4%
  30개+        n=  32  평균 4.09  5점 59.4%  3점이하 25.0%
```

리뷰를 많이 써 본 사람일수록 점수가 내려간다. 30개 이상 작성자 기준
4.09점, 10개 이상 기준 4.45점. **표시 평점 4.9는 약 0.45~0.8점 부풀려져 있다.**

작성 시각도 식사시간대에 95.2% 몰려 있고 12시(548건)와 18-19시(704건)에
두 개의 봉우리가 선다. 집에 가서 쓴 리뷰가 아니라 테이블에서 쓴 리뷰다.

### 판정

가짜 손님이 쓴 허위 후기(대행업체 발주)가 아니라, **실제 방문객에게 보상을 주고
만점 리뷰를 받아내는 리뷰 이벤트형 별점 세탁**이다. 방문 자체는 진짜다.
사진 98.5%, 식사시간대 집중 92%는 테이블에서 즉석 작성했다는 뜻이고,
1회성 계정 70%는 그 자리에서 계정을 만들었다는 뜻이다.

실제 평가는 "4.9점 인생 맛집"이 아니라 **4.1~4.5점대의 괜찮지만 비싼 집**에 가깝다.
불만은 가격 대비 양, 웨이팅, 여름철 냉방, 퓨전이라 호불호로 일관되게 모인다.

## 한계

- 카카오맵이 공개하는 범위(작성자의 전체 리뷰 수, 평생 평균 평점, 팔로워 수)만
  쓴다. 계정 생성일이나 기기 정보는 볼 수 없으므로 개별 리뷰를 "가짜"로
  단정하지 않고 집단 분포로만 판단한다.
- 대조군 표본이 작은 업장(50~90건)은 비율의 오차가 크다. 가능하면 리뷰 수가
  비슷한 업장을 대조군으로 넣는 편이 낫다.
- 개점 직후에는 1회성 계정 비중이 자연스럽게 올라간다. 월별 추이가 계속
  70% 근처로 평탄한지, 개점 초기에만 높은지 함께 봐야 한다.
- 수집은 페이지당 0.25초 간격을 둔다. 간격을 줄이지 말 것.
